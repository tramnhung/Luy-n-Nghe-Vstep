# Luyện nghe VSTEP — English 1 (Listening & Speaking), UFM

Trang luyện nghe trực tuyến cho sinh viên: nghe từng đoạn, làm bài, chấm điểm và xem đáp án ngay.

- `index.html` — mục lục các bài nghe (trang sinh viên vào đầu tiên)
- `nghe1.html` — Nghe 1, Part 1, Bài 1 (8 câu), có mã nộp bài để lấy điểm
- `test01.html` — Test 01 đầy đủ: Part 1 (8 câu), Part 2 (3 câu), Part 3 (2 câu), kèm đáp án, transcript, giải thích tiếng Việt và từ vựng
- `bangdiem.html` — trang bảng điểm dành cho giảng viên
- `media/` — file nghe (`media/test01/` là audio của Test 01)
